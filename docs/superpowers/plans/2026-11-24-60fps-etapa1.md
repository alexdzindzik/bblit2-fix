# 60 fps, etapa 1: gravador e ritmo (sem interpolar) — plano

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Gravar o desenho de cada tick do jogo e, na espera do jogo, redesenhar esse mesmo instantâneo nos quadros extras, levando o contador a 60/120/144 fps com a imagem idêntica à de hoje.

**Architecture:** Os ganchos OpenGL que o mod já tem passam a gravar cada comando do jogo num instantâneo (`src/glrec.c`, puro e testado). A chamada à espera do jogo (`call 0x415700` em `0x4013a1`) passa a ir para `bbfix_pacer`, que, até o prazo do tick, repete o instantâneo pelos próprios ganchos (assim HUD HD, sombra, FBO e efeitos valem) e troca o quadro. Os horários dos quadros extras vêm de `src/pacer.c`, puro e testado. Com `fps=30` nada disso é instalado.

**Tech Stack:** C11, MinGW-w64 i686 (DLL), gcc no Linux para os testes, OpenGL 1.1 do jogo.

**Spec:** `docs/superpowers/specs/2026-11-24-60fps-design.md` (Desenho §1, §2, §6; Etapas, item 1).

## Global Constraints

- Só o `bblit2.exe` PT-BR (o mod já desliga tudo em outro exe).
- `[video] fps=30` (padrão) = comportamento da 0.13.1: nenhum gancho novo, nenhum patch novo.
- Valores aceitos de `fps`: 30, 60, 120, 144 (outro valor: 30, com aviso no log).
- Endereços: espera `0x415700`, chamada em `0x4013a1` (bytes `E8 5A 43 01 00`), prazo `[0x639b10]` (int64, QPC), ticks `[0x639af0]` (int64, QPC por tick), pular desenho `[0x4d07f8]`.
- Recursos não entram no instantâneo: `glTexImage2D`, `glTexSubImage2D`, `glDeleteTextures` executam na hora; `glDeleteTextures` e `wglDeleteContext` invalidam o instantâneo atual.
- Comentários e mensagens de log em português, no estilo do `bbfix.c`. Testes no `build.sh` (gcc do Linux), como os existentes.
- Commits no nome do Alessandro Dzindzik, com as linhas `Co-Authored-By`/`Claude-Session`; commit e push só com o OK do Night, no fim da etapa.

## Review Focus

1. O jogo atrasado (PC lento, carregamento): com `[0x4d07f8]` ligado ou sem tempo até o prazo, nenhum quadro extra; o jogo não pode entrar em espiral de atraso.
2. Fase carregando (texturas apagadas e reenviadas): nenhum quadro extra com textura apagada (quadro branco ou preto).
3. Pausa, textos e menus do jogo em OpenGL: o quadro extra sai igual; nos menus GDI do início a espera não é chamada e nada muda.
4. Jogo sem foco (`background=1`) e minimizado: sem quadros extras com a janela minimizada.
5. HUD HD e sombra do HUD nos quadros extras: iguais aos do quadro do jogo (conferido pela captura dupla do F12).

### Task 1: Instantâneo dos comandos (`glrec`)

**Files:**
- Create: `src/glrec.h`, `src/glrec.c`
- Test: `tests/test_glrec.c`
- Modify: `build.sh` (teste e fonte da DLL)

**Interfaces:**
- Produces:
  - `enum { GR_BEGIN = 1, GR_END, GR_VERTEX, GR_COLOR, GR_TEXCOORD, GR_BIND, GR_ENABLE, GR_DISABLE, GR_BLENDFUNC, GR_ALPHAFUNC, GR_DEPTHFUNC, GR_DEPTHRANGE, GR_SHADEMODEL, GR_POLYGONMODE, GR_HINT, GR_CLEARCOLOR, GR_CLEAR, GR_VIEWPORT, GR_SCISSOR, GR_MATRIXMODE, GR_LOADIDENTITY, GR_ORTHO, GR_TEXPARAM, GR_N };` e `#define GR_RAW 0x100` (bit no `op`: aplicar direto no OpenGL, sem passar pelos ganchos do mod)
  - `typedef struct { unsigned op, u[3]; double d[6]; } GR_CMD;`
  - `typedef struct { GR_CMD *cmd; int n, cap, overflow; } GR_SNAP;`
  - `void gr_init(GR_SNAP *s, GR_CMD *buf, int cap);`
  - `void gr_reset(GR_SNAP *s);` (n = 0, overflow = 0)
  - `int gr_put(GR_SNAP *s, unsigned op, const unsigned *u, int nu, const double *d, int nd);` (1 = gravou; 0 = cheio, marca overflow; u/d que faltam ficam 0)
  - `int gr_replay(const GR_SNAP *s, void (*fn)(const GR_CMD *c, void *ctx), void *ctx);` (devolve quantos comandos repetiu; com overflow, 0 e não chama `fn`)
  - Uso por comando: VERTEX d = x, y, z e u[0] = ponteiro do jogo; COLOR d = r, g, b, a; TEXCOORD d = s, t, r, q; BIND u = alvo, nome; ENABLE/DISABLE u[0]; BLENDFUNC u[0..1]; ALPHAFUNC u[0], d[0]; DEPTHFUNC/SHADEMODEL/CLEAR/MATRIXMODE u[0]; DEPTHRANGE d[0..1]; POLYGONMODE/HINT u[0..1]; CLEARCOLOR d[0..3]; VIEWPORT/SCISSOR d[0..3]; ORTHO d[0..5]; TEXPARAM u = alvo, parâmetro, d[0] = valor.

  - `test_float_exact`: um valor `float` gravado (ex.: `-1280.0f`, `0.018f`, `65536.0f`) volta exatamente igual ao ser convertido de volta para `float`.
  - `test_overflow`: com `cap = 2`, o 3º `gr_put` devolve 0, `overflow == 1` e `gr_replay` devolve 0 sem chamar `fn`.
  - `test_reset`: depois de `gr_reset`, `n == 0`, `overflow == 0` e uma nova gravação funciona.
  - `test_raw_flag`: `GR_ENABLE | GR_RAW` volta com o bit `GR_RAW` intacto.

### Task 3: Gravar o desenho do jogo (`bbfix.c`)

**Files:**
- Modify: `src/bbfix.c`, `dist/bblit2fix.ini`

**Interfaces:**
- Consumes: `glrec.h` (Task 1).
- Produces (em `bbfix.c`):
  - `cfg.fps` (`ini_int("video", "fps", 30)`, valida como nas Global Constraints; log em `config:`).
  - `static GR_SNAP g_rec; static int g_rec_on, g_replaying, g_rec_ok;` (`g_rec_on` = `cfg.fps > 30` e GL do jogo ativo; `g_rec_ok` = instantâneo completo e válido para este tick)
  - `static void rec(unsigned op, unsigned u0, unsigned u1, unsigned u2, const double *d, int nd);` (não grava quando `!g_rec_on || g_replaying`)
  - `static void rec_start(void);` (zera o instantâneo e grava o estado inicial lido com `glGet*`/`glIsEnabled`, cada um com `GR_RAW`: `GL_BLEND`, `GL_DEPTH_TEST`, `GL_ALPHA_TEST`, `GL_TEXTURE_2D`, `GL_CULL_FACE`, `GL_SCISSOR_TEST`, função de blend, alpha, profundidade, textura ligada, viewport e scissor reais, modo de matriz)
  - `static void replay_cmd(const GR_CMD *c, void *ctx);` (sem `GR_RAW`: chama o gancho `h_*` correspondente com os valores gravados; com `GR_RAW`: chama a função real `r_*`/OpenGL)

- [ ] **Step 1: Ganchos que faltam**, só instalados com `cfg.fps > 30` (tabela própria no `h_GetProcAddress`, como a `gl_dbg_hooks`): `glBlendFunc`, `glAlphaFunc`, `glDepthFunc`, `glDepthRange`, `glShadeModel`, `glPolygonMode`, `glHint`, `glClearColor`, `glLoadIdentity`, `glColor3fv` (já existe no ramo para o F5; passa a valer também com `fps > 30`). Com `fps > 30`, os ganchos de desenho (`gl_probe_hooks`) também são instalados.

- [ ] **Step 2: Gravar em cada gancho** os comandos da lista da Task 1, com os argumentos crus que o jogo passou (antes de `map_rect` etc.): Begin, End, todas as variantes de Vertex (→ `GR_VERTEX`, com o ponteiro quando houver), de Color (→ `GR_COLOR`, alfa 1 nas de 3 componentes), de TexCoord (→ `GR_TEXCOORD`, com r = 0 e q = 1 nas de 2 componentes), BindTexture, Enable, Disable, Viewport, Scissor, Clear, MatrixMode, LoadIdentity, Ortho, TexParameterf/i e os da Step 1. `glFlush`/`glFinish` não são gravados. `glLoadMatrixf/d`: não gravados; registrar uma vez no log se o jogo chamar com `fps > 30`.

- [ ] **Step 3: Começo e fim do instantâneo**: no fim do `after_swap` (troca do jogo), `g_rec_ok = g_rec.n > 0 && !g_rec.overflow`, depois `rec_start()`. `glDeleteTextures` e `wglDeleteContext` zeram `g_rec_ok`. O buffer (200 000 comandos) é alocado uma vez quando `fps > 30`.

- [ ] **Step 4: `replay_cmd`** com um `switch` por `op`, chamando os ganchos para os comandos normais e as funções reais para os `GR_RAW`.

- [ ] **Step 5: `dist/bblit2fix.ini`**: em `[video]`, `fps=30` com o comentário "60, 120 ou 144: quadros extras (em desenvolvimento, por enquanto a imagem só é repetida); 30 = original".

- [ ] **Step 6: Verificação**
